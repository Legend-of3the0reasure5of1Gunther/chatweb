# 安全聊天系统 - 数据库操作模块

## 概述
本模块提供了完整的数据库操作功能，包括连接池管理、事务处理、批量操作、备份恢复、迁移管理等。

## 功能特性

### 1. 连接池管理
- 连接复用，减少开销
- 最大连接数限制
- 连接超时处理
- 自动重连机制

### 2. 查询执行
- 参数化查询（防SQL注入）
- 预处理语句支持
- 批量操作支持
- 结果集自动管理

### 3. 事务管理
- 完整的事务支持
- 保存点（Savepoint）
- 自动回滚机制
- 事务嵌套支持

### 4. 备份与恢复
- 在线热备份
- 压缩备份支持
- 完整性校验
- 自动备份调度

### 5. 数据库维护
- VACUUM优化
- 完整性检查
- 索引重建
- 统计信息更新

### 6. 迁移管理
- 版本化迁移
- 迁移回滚
- 迁移状态跟踪
- 自动迁移应用

## 编译和安装

### 依赖项
- SQLite 3.31.0 或更高版本
- OpenSSL 1.1.1 或更高版本
- Zlib 1.2.11 或更高版本
- POSIX线程库
