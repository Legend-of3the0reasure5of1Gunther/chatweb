# 安全聊天系统 - 认证授权模块

## 概述
本模块提供了完整的用户认证和授权功能，包括用户注册、登录、会话管理、权限控制等。

## 功能特性

### 1. 用户认证
- 用户注册和登录
- 密码哈希存储（PBKDF2-HMAC-SHA256）
- 账户锁定机制
- 登录尝试限制
- 会话管理

### 2. 令牌管理
- JWT风格访问令牌
- 刷新令牌机制
- 令牌验证和刷新
- 令牌撤销

### 3. 权限控制
- 基于角色的访问控制（RBAC）
- 细粒度权限管理
- 权限继承和组合

### 4. 安全特性
- 密码强度验证
- 防暴力破解保护
- IP地址限制
- 安全日志记录
- 内存安全操作

### 依赖项
- OpenSSL 1.1.1 或更高版本
- SQLite3 3.31.0 或更高版本
- POSIX线程库
